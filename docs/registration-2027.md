# Registration 2027

New registrations use EUR: Full Arranged 1699, Self Arranged 1499. Save Exchange is optional and costs 249. The first payment is 232 without protection or 481 with it. A correction reduces the contract total and final installment, not the initial payment or protection fee.

The public form uses the numeric field “Корекция на програмната такса (евро)” instead of a promotional code. Per the owner's explicit choice, every applicant may enter the amount. Amounts are whole multiples of 10 from 0 to 690; the server independently validates them and saves the resulting price. The existing code API remains available for compatibility, but a code and numeric correction cannot be combined.

The admin's **Discount codes** section manages codes. For example, create AIM80 with amount 80, season 2027, a usage limit and expiry date to offer Full Arranged for 1619. The code name alone never determines its value. No active codes are seeded. Usage is reserved transactionally with the application; failed document generation retains that reservation for admin regeneration rather than creating a second application.

The applicant receives the contract PDF, the annex PDF when protection is selected, and bank details PDF. Registrations are copied to studentski@aimtravel.bg. A separate notification with subject “Нов записан участник онлайн” goes to that inbox with participant contact details, program, contract number and an admin link. It is attempted independently of applicant delivery and tracked by ContractDocument.staff_notified_at; retries skip a notification already accepted by the mail transport. Admins can retry a failed notification without resending the student documents. Apply migration 0005 before enabling this behavior. The email links to the online Application Form. Legacy USD applications retain their original rendering and email behavior.

The sanitized Full, Self and annex DOCX templates are in templates/apply/documents. The annex uses the saved discounted contract price and references article 19 for Full or 18 for Self. The PDF renderer uses the filled document text and bundled Cyrillic fonts; it reflows paragraphs rather than reproducing Word pagination. Unsupported document structures stop generation for review.

Deployment requires migration apply.0004_eur_pricing_and_protection, the new templates, bundled fonts and a frontend build. Verify the staging database is separate before migration. Build assets are generated by CI and are not committed. Keep private contract storage outside public media. Production deploy remains the existing main-branch workflow.

Validation: pricing and code limits, Cyrillic names, idempotency, PDF/annex content, email attachments and email failure reporting are covered by tests/test_apply_eur.py and tests/test_apply_form.py. Inspect rendered PDF pages whenever changing a document template or renderer.
