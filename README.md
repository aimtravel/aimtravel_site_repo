This repository contains the source code of AIM Travel Agency website. 

It has different purposes.

1. Informational function - people can find useful information for WAT USA program, as well as job offers and process related information.
2. Account managing function:
2.1. After login end-user can fill-out WAT Registration form
2.2. After login end-user can fill-out TaxRefund Application in order to participate in tax refund process
