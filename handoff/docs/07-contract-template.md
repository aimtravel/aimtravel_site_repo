# Превръщане на договора в темплейт

Това е стъпката, която ще те забави най-много, и единствената, която изисква
ръчна работа във Word. Прочети я, преди да я започнеш.

## Проблемът

`AIM_Travel_WAT_Contract_template_2026.docx` се казва „template“, но не е
темплейт. Това е **попълнен договор на конкретен участник**, с истински имена,
ЕГН и телефон вътре:

> Днес, 26.08.2026 гр. София между: 1. „Агенция за Международна Мобилност” ООД,
> ЕИК 203634922, представлявано от Росен Антонов … и **2. Ясен Яворов Михов,
> ЕГН: 0045206400**, гражданин на България, студент редовно обучение,
> **тел: 0885281940**, Email: **yasen.mihov@gmail.com** …

Данните се повтарят на две места: в началото на договора и в **декларацията**
накрая. И двете трябва да станат плейсхолдъри, иначе декларацията ще излиза с
чуждо име.

## Какво да замениш

Отвори файла в Word/LibreOffice и замени точно тези низове с `{{ }}` изрази.
`docxtpl` използва Jinja2 синтаксис.

| Намери в документа | Замени с | Бележка |
| --- | --- | --- |
| `26.08.2026` (двете места) | `{{ today }}` | и в договора, и в декларацията |
| `гр. София` (двете места) | `гр. {{ city }}` | градът на офиса, не винаги София |
| `Ясен Яворов Михов` (двете места) | `{{ full_name }}` | латиница, както е в паспорта |
| `0045206400` (двете места) | `{{ egn }}` | |
| `0885281940` (двете места) | `{{ phone }}` | |
| `yasen.mihov@gmail.com` (двете места) | `{{ email }}` | внимавай: има и HYPERLINK поле |
| `Росен Антонов` | `{{ manager_name }}` | |
| `лято 2027 г.` в чл. 1 | `лято {{ season }} г.` | |
| `“FULL ARRANGED”` в чл. 1 | `“{{ program_option }}”` | |
| `$1750` в чл. 9 | `${{ price_usd }}` | SELF ARRANGED е $1250 |

**Добави ново поле за номера на договора.** Днес договорът няма номер.
Сложи го в заглавната част, непосредствено под „Договор“:

```
Договор № {{ contract_number }}
```

**Добави и номера на лична карта** — той е в новата форма, но го няма в
стария договор. Препоръчително място: до ЕГН-то в т. 2.
Плейсхолдър: `{{ id_card_number }}`.

## Капани във Word

**Разкъсани текстови полета.** Word често разбива един низ на няколко `<w:r>`
елемента заради проверка на правописа или следа от редакция. Ако напишеш
`{{ full_name }}` и то се раздели на `{{ full_` и `name }}`, docxtpl няма да
го разпознае и ще остави текста както е.

Лек: избери целия абзац, изчисти форматирането (Ctrl+Space), и напиши
плейсхолдъра наведнъж, без да мърдаш курсора.

**HYPERLINK полето на имейла.** В оригинала имейлът е линк:
`HYPERLINK "mailto:yasen.mihov@gmail.com"yasen.mihov@gmail.com`. Махни
хиперлинка (десен бутон → Remove Hyperlink) преди да сложиш плейсхолдъра,
иначе линкът ще сочи към чужд адрес в готовия договор.

**Автоматична замяна на кавички.** Word превръща `"` в „ “ “. Вътре в
`{{ }}` това чупи Jinja2. Изключи автоформатирането, докато редактираш.

## Един темплейт на сезон

Файлът се именува `contract_{season}.docx` — например `contract_2027.docx` —
и се слага в `settings.AIM_CONTRACT_TEMPLATES`.

Причината не е техническа: цените, сроковете и условията се менят всяка
година, а вече издадените договори трябва да могат да бъдат регенерирани
точно както са били подписани. Един общ темплейт с `{% if season == 2027 %}`
би пренаписал историята.

`contracts.render_contract` хвърля `FileNotFoundError` с обяснение, ако
темплейтът за сезона липсва — това е нарочно, за да не се генерира договор
по грешна година.

## Проверка

Management команда за ръчна проверка:

```bash
python manage.py shell -c "
from apps.apply.models import Application
from apps.apply.contracts import render_contract
app = Application.objects.latest('created_at')
print(render_contract(app).pdf_path)
"
```

Отвори PDF-а и провери:

- [ ] Номерът на договора е в заглавната част.
- [ ] Името, ЕГН и телефонът са верни и в договора, **и в декларацията накрая**.
- [ ] Няма останали `{{ }}` никъде в документа.
- [ ] Кирилицата се вижда — не квадратчета. Ако са квадратчета, в контейнера
      липсват шрифтове: `fonts-dejavu fonts-liberation`.
- [ ] Цената отговаря на избраната програмна опция.
- [ ] Градът е този на избрания офис.

## LibreOffice в контейнера

```dockerfile
RUN apt-get update && apt-get install -y --no-install-recommends \
    libreoffice-writer fonts-dejavu fonts-liberation \
 && rm -rf /var/lib/apt/lists/*
```

`soffice --headless` държи профилна директория. При паралелни Celery работници
това може да доведе до конфликт — ако видиш случайни провали, дай на всеки
процес собствен `-env:UserInstallation=file:///tmp/lo-$$`.
