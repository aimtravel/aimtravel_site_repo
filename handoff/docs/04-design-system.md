# Дизайн система

Палитрата е извлечена от aimtravel.bg, не е измислена. Първата ми версия беше
teal/amber и беше отхвърлена — не използвай нищо извън тези токени, без да питаш.

## Цветове

| Токен | Hex | HSL | Употреба |
| --- | --- | --- | --- |
| `--primary` | `#A31D1A` | `1 72% 37%` | CTA, активна стъпка, грешки |
| — hover | `#7F1512` | | |
| `--coral` | `#E8635C` | `3 75% 64%` | акцент **само върху тъмно** |
| `--secondary` / navy-700 | `#12395F` | `210 68% 22%` | заглавия |
| navy-800 | `#0D2B47` | | тъмни секции, badges |
| navy-900 | `#071726` | | футър, дъно на градиенти |
| navy-500 | `#2C5B87` | `210 51% 35%` | фокус пръстен |
| `--muted` | `#F4F5F7` | | фон на страницата |
| `--border` | `#E2E6EB` | | рамки |
| `--foreground` | `#1C2430` | | основен текст |
| `--muted-foreground` | `#55606E` | | втори план |
| `--success` | `#1E7A4C` | | |

**Тъмна тема не е огледало.** `#A31D1A` върху тъмен фон пада под 4.5:1,
затова в dark режим основният цвят светва до `#D9483F`. Всичко това е в
`src/styles/tokens.css`.

Фокус пръстенът е тъмносин (`navy-500`), а не червен — иначе фокус и грешка
изглеждат еднакво.

## Типография

| Роля | Шрифт | Тегла |
| --- | --- | --- |
| Заглавия | Montserrat | 600 / 700 / 800, uppercase |
| Текст | Manrope | 400 / 500 / 600 / 700 |
| Данни, номера, етикети | JetBrains Mono | 400 / 500 / 700 |

**Всяко зареждане на шрифт носи `&subset=cyrillic,cyrillic-ext,latin`.**
Без това Montserrat няма кирилски глифи, браузърът пада към system-ui само за
тях и заглавията излизат наполовина в друг шрифт.

Трите имена, ЕГН, лична карта, телефон и номерът на договора са в mono: това са
данни за сверяване знак по знак, не проза.

## Бранд мотиви от съществуващия сайт

- Кръгло лого с арка/мост в бял контур.
- Извити „куполни“ преходи между секциите (`border-radius: 50% 50% 0 0`).
- Американски мотиви — звезди, вертикални червени ивици.
- Тъмносини градиенти върху градски снимки в hero секцията.
